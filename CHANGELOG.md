# Что нового

## 0.9.1
- Whisper: исправлена ошибка «open() got an unexpected keyword argument 'metadata_errors'» — звук теперь подаётся без PyAV.
- Полоска прогресса поверх видео для распознавания речи и перевода ряда.
- Каждый фильм запоминает свои субтитры, сдвиг и подгонку — при повторном открытии всё восстанавливается само.
- Субтитры «рядом с фильмом» берутся только с похожим именем, чтобы не предлагать чужие.
- Разделы настроек сворачиваются по нажатию на заголовок.

## 0.9.0
- Расшифровка речи из фильма через Whisper (faster-whisper на ПК): субтитры слово в слово с озвучкой и точная подсветка слов.
- В окне выбора субтитров — новая группа «Из звука фильма». Можно сразу смотреть, ряд появится, когда распознавание закончится.
- Настройки → Распознавание речи: выбор модели small / medium / large-v3, поиск и установка faster-whisper.

## 0.8.0
- Мягкая подсветка произносимого слова в субтитрах (Настройки → Ряд → «Подсвечивать произносимое слово»).
- Приложение для планшета теперь приезжает вместе с обновлением ПК — левый QR-код работает без GitHub.

## 0.7.0
- Планшет: ПК раздаёт фильмы по домашней сети. Настройки → Планшет: папки с фильмами, привязка по QR.
- Приложение для Android собирается на GitHub и раздаётся с ПК по QR-коду.
- Сворачивание в трей и запуск вместе с Windows, пока включена раздача.

## 0.6.0
- Кнопка «Обновить»: плеер сам скачивает новую версию с GitHub и перезапускается.
- Подгонка субтитров под голоса: автоматически и вручную «По реплике».
- Поиск SubDL по имени файла, по английскому названию и выбор фильма из похожих.
- Перевод: Claude → Google → MyMemory, если что-то недоступно.

## 0.3.0
- Первая версия для Windows: два ряда субтитров, SubDL и OpenSubtitles, перевод по клику, словарь.
