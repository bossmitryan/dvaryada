# Что нового

## 0.8.0
- Мягкая подсветка произносимого слова в субтитрах (Настройки → Ряд → «Подсвечивать произносимое слово»).
- Приложение для планшета теперь приезжает вместе с обновлением ПК — левый QR-код работает без GitHub.

## 0.7.0
- Планшет: ПК раздаёт фильмы по домашней сети. Настройки → Планшет: папки с фильмами, привязка по QR.
- Приложение для Android собирается на GitHub и раздаётся с ПК по QR-коду.
- Сворачивание в трей и запуск вместе с Windows, пока включена раздача.

## 0.6.0
- Кнопка «Обновить»: плеер сам скачивает новую версию с GitHub и перезапускается.
- Подгонка субтитров под голоса: автоматически и вручную «По реплике».
- Поиск SubDL по имени файла, по английскому названию и выбор фильма из похожих.
- Перевод: Claude → Google → MyMemory, если что-то недоступно.

## 0.3.0
- Первая версия для Windows: два ряда субтитров, SubDL и OpenSubtitles, перевод по клику, словарь.
