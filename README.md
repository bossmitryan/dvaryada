# ДваРяда — плеер с двойными субтитрами (Windows)

## Запуск
1. Установите Node.js LTS: https://nodejs.org (один раз).
2. Дважды щёлкните `start.bat`. Первый запуск скачает Electron и ffmpeg (2–5 минут), дальше открывается сразу.
3. Чтобы получить обычный `.exe` без Node.js: запустите `build.bat`, результат появится в папке `dist`
   (`DvaRyada 0.2.0.exe` — портативная версия, `DvaRyada Setup 0.2.0.exe` — установщик с привязкой к .mkv/.mp4).

## Поиск субтитров: SubDL (основной)
1. Откройте https://subdl.com/panel/api и войдите (можно через Google).
2. Скопируйте API-ключ.
3. Вставьте его в окне выбора субтитров (появится при первом открытии фильма) или в «Настройки → SubDL».
Бесплатно: около 2000 поисков и 300 скачиваний в сутки. Скачанные субтитры плеер запоминает.

## OpenSubtitles (по желанию)
Второй источник. Сайт opensubtitles.com часто застревает на проверке Cloudflare; если у вас он открывается —
профиль → API consumers → создать ключ, затем «Настройки → OpenSubtitles».

## Что происходит при открытии фильма
- Сразу открывается окно «Какие субтитры нужны?».
- Параллельно: плеер читает дорожки файла (встроенные субтитры и озвучки), ищет .srt рядом с фильмом и в папке Subs,
  ищет на SubDL (и OpenSubtitles, если подключён) по названию (название и год распознаются из имени файла).
- Для каждого варианта кнопки «Ряд 1» / «Ряд 2». Лучшие варианты на ваших языках отмечаются заранее.
- «Смотреть» — скачивает выбранное и запускает фильм. Сменить позже: кнопка «Сменить» или клавиша C.

## Форматы
Видео с кодеками, которые не понимает встроенный движок (HEVC, AC3, DTS, AVI и т.п.), и выбор другой озвучки
работают через ffmpeg: звук перекодируется в AAC, видео при необходимости в H.264. Для 4K HEVC нужен неслабый процессор.

## Перевод слов
Клик по слову — перевод; выделение нескольких слов — перевод выражения.
Google — бесплатно, без ключа. Claude — объяснение смысла в контексте фразы, нужен ключ Anthropic (платный).

## Структура
- `main.js` — окно, настройки, связь с интерфейсом
- `lib/media.js` — ffprobe/ffmpeg: дорожки, извлечение субтитров
- `lib/server.js` — локальный сервер видео и перепаковка на лету
- `lib/opensubs.js` — OpenSubtitles REST API v1
- `lib/translate.js` — перевод
- `renderer/` — интерфейс плеера
